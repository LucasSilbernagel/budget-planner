# An INDEXING PREFERENCE, not a security control. Nothing here protects
# anything: the free tier keeps every figure in the visitor's own browser, so a
# crawler fetching /income sees an empty page regardless of this file. These
# rules exist so that a search result for "Longhand Budget" is the homepage, the
# pricing page or a documentation page — the surfaces that actually say
# something to someone who has not used the app — rather than an empty
# app screen. Do not describe any line below as a protection.
#
# Indexable (covered by the `Allow: /` below, which nothing further restricts):
# /, /pricing, /contact, /docs and /docs/*, /terms, /privacy, /refund. `/` is
# here because it is the site root a search result must be able to reach — it
# doubles as the Overview screen, so it is the one page that is both.
#
# Every page route is EITHER in that list OR under a `Disallow:` below, and
# `src/routes/__tests__/robots-sitemap-coverage.test.ts` fails if a route is in
# neither. Adding a route means deciding which, in this file.
#
# `Sitemap:` added by story seo-1. Story 40.1 left it out because there was no
# production origin; that origin is now settled (ADR-007). The URL must be
# absolute, and its origin must match every <loc> in sitemap.xml — the same
# coverage test checks both. sitemap.xml lists exactly the indexable pages.
